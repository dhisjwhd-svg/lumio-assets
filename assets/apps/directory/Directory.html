Field Guide

How to post links and check them on your own school computer.

One shared list. Personal results.

Our team maintains the main Links list and publishes updates from time to time. The shared page is designed to be embedded using GitHub Raw content or jsDelivr, so visitors can open the latest published version when the embedded file is updated. Your own ✓ or × checks remain local to your browser and do not change Lightspeed filtering or other students’ results.

01

Post a link manually

Choose ＋ Add link in the sidebar. Enter the site name, paste its full web address beginning with https://, choose a category, then select Save link. The new entry appears on the Links page in this browser.

↓ ADD LINK
02

Test it on your school device

Open the site from its address on the card. Wait for it to load normally. If it opens, mark ✓. If it is blocked by your school’s filter or fails to load, mark ×. These are student reports, not automatic detection.

OPEN → CHECK
03

Keep the list tidy

✓ moves the link to Your Notes, your local list of links that worked for you. × moves it to Trash, your local list of links reported blocked or not working. You can restore a link if you tested it again and it works.

✓ NOTES / × TRASH
04

How team updates reach you

Our team adds and reviews links, then updates the HTML list in the GitHub repository. The page can be served through GitHub Raw content or a jsDelivr embed/CDN link. We publish changes occasionally, so reload the updated page to see the latest team list. Your personal ✓ / × choices are separate from these published updates.

TEAM EDITS → PUBLISH → REFRESH
Important: Published team links are shared when the hosted HTML is updated; personal additions, Notes, and Trash are stored in your browser and do not automatically publish back to GitHub. The Test link button opens the site on your device, but this page cannot automatically detect or change school filter settings. If a site should be available for classwork, ask a teacher or school IT staff to review it.
